# FORUS Sport

Static public information website for https://sport.forus.digital/.

Serve the `dist` directory with any static host. No package installation, build, application server, accounts, database, payments or runtime integrations are required.

The site adapts the supplied FORUS Sports Network reference, including its artwork, black/orange identity, five sports and five country plans. Content describes the proposed network; it does not present planned services as already operating. Enquiries link to the existing public FORUS contact page.

Edit `dist/index.html` for content, `dist/public.css` for the public-site styling and `dist/app.js` for the mobile menu. `dist/styles.css` contains the reference design styles. All images are local in `dist/assets`.
